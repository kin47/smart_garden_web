## Deploy
### Command:
#### Build Web
```flutter build web```

#### Deploy Firebase
```firebase login```
```firebase init hosting```
```firebase deploy```

#### Note:
- Cần cài đặt firebase-tools
- Khi deploy không dùng BASE_URL mà set string cứng
